# Дизайн: портал возврата после победы Desert Scourge

**Статус:** утверждён пользователем без дополнительного согласования.

## Цель

После победы над Desert Scourge оставить игроков на арене для сбора дропа и создать портал, через который они по собственной инициативе возвращаются в основной мир.

## Подходы

1. **Интерактивный projectile-портал с ванильной текстурой — выбранный.** После подтверждённой победы появляется один визуальный портал у пола арены. В одиночной игре касание портала вызывает `SubworldLibrary.Call("Exit")`. Не нужны новые PNG-ресурсы или постоянные тайлы.
2. **Штатная кнопка Return — отклонён.** Функциональна, но не обозначает окончание боя внутри арены.
3. **Кастомный ModTile-портал — отложен.** Нужны графика, тайл-кадры и отдельная обработка взаимодействия; для текущей заглушки избыточно.

## Границы

- Только одиночная игра.
- Портал появляется только после гибели отслеживаемого arena-босса при наличии живого участника.
- Поражение сохраняет отдельный автоматический возврат; портал для него не создаётся.
- В multiplayer/dedicated server не добавлять поведение без игрового прогона.
