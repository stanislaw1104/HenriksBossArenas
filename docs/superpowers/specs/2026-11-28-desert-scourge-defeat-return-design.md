# Дизайн: возврат после поражения Desert Scourge

**Статус:** ожидает утверждения.

## Цель

В одиночной игре завершать сеанс Desert Scourge как поражение, когда участник арены погиб, а босс ушёл. Игрок должен вернуться из subworld на мировую точку появления основного мира.

## Границы

- Поддерживается только `NetmodeID.SinglePlayer`.
- Multiplayer и dedicated server не реализуются и не объявляются поддержанными: текущий переход в arena subworld для них намеренно отключён.
- Победа, награды и респавн внутри арены остаются отдельными задачами.
- Автовозврат применяется только при поражении. После победы участники остаются на арене, чтобы собрать дроп, и возвращаются вручную штатной кнопкой `Return` Subworld Library. Отдельный портал — будущая UX-задача, если этот механизм окажется неудобным.

## Подходы

1. **Одиночная сессия с явной причиной завершения — выбранный.** `ArenaSessionSystem` распознаёт отсутствие живых участников во время активной арены, удаляет отслеживаемого босса, очищает сессию и вызывает документированный `SubworldLibrary.Call("Exit")`. После возврата игрок переносится на `Main.spawnTileX/Main.spawnTileY` уже восстановленного основного мира.
2. **Немедленная телепортация без выхода из subworld — отклонён.** Игрок остался бы на пустой карте арены, а бой и карта не были бы корректно завершены.
3. **Сразу реализовать сетевой возврат всех игроков — отложен.** Subworld Library использует отдельный subserver, поэтому понадобится серверно-авторитетное состояние, передача данных между мирами и реальный multiplayer-прогон.

## Последовательность

1. Игрок погибает в активной Desert Scourge arena.
2. Когда босс становится неактивным и живых участников не остаётся, система классифицирует результат как поражение.
3. Система очищает session state и выходит из subworld.
4. Callback после загрузки основного мира переносит игрока на мировую точку появления.

## Проверки

- Чистые тесты проверяют классификацию результата: неактивный босс и отсутствие живых участников означают поражение.
- Ручной одиночный прогон: погибнуть, дождаться ухода босса, оказаться в основном мире на мировом spawn.
- Автоматически: `ArenaLogicTests`, entrypoint-проверка и MSBuild.
