# Дизайн: удержание лута Desert Scourge на арене

**Статус:** утверждён пользователем.

## Цель

Не позволять выпавшим предметам оказаться за стенами арены или под её полом, сохранив игроку возможность собрать лут там, где он выпал.

## Выбранный подход

`GlobalItem.PostUpdate` действует только в активном `DesertScourgeArenaSubworld`. Он зажимает hitbox каждого активного world-item во внутреннем прямоугольнике арены. Если позиция была исправлена, компонент скорости по скорректированной оси сбрасывается, поэтому предмет не продолжает двигаться за границу.

Это распространяется на любой предмет, выпавший на арене: дроп босса, расходники и предметы игрока. Предметы не телепортируются в общую точку и не удаляются.

## Границы

- Ограничение действует только во время активного Desert Scourge subworld и не затрагивает основной мир.
- Внутренняя граница совпадает с игровой зоной: за одной клеткой стен, над полом и под потолком, с учётом ширины и высоты item hitbox.
- По оси X гасится скорость только при касании боковой границы; по оси Y — только при касании пола или потолка.
- Одиночная игра является единственным проверяемым режимом; multiplayer/dedicated server не заявляются поддержанными.
