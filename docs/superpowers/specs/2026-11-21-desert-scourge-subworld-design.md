# Дизайн: арена Desert Scourge в отдельном subworld

**Статус:** утверждён; реализован частично.

## Текущий этап

Первым реализуется и проверяется одиночный сценарий. Multiplayer и выделенный сервер исключены из текущего этапа: для них нет возможности провести честный игровой прогон с несколькими участниками.

Арена-заглушка — пустая прямоугольная коробка из sandstone brick: пол, боковые и верхняя границы; внутри только воздух. Под полом располагается массив песка. Это сохраняет штатное определение пустынного биома Terraria и Calamity, чтобы игра рисовала пустынный фон, не требуя ручной отрисовки или подмены фона.

## Цель

Заменить временную арену в основном мире на отдельный subworld: после призыва Desert Scourge участники переходят в независимую карту арены, после смерти возрождаются там же, а после победы возвращаются в основной мир.

## Почему меняется подход

Координат за физической границей мира Terraria не существует. Текущий прототип строил временную арену внутри основного мира, поэтому её можно было увидеть, а ошибочный снимок `Tile` повредил ландшафт: `Tile` в tModLoader — индекс в глобальном хранилище, а не переносимое значение.

Subworld Library создаёт отдельный мир и для multiplayer запускает отдельный subserver. Это единственный выбранный способ получить реальную отдельную карту без тайлов в основном мире.

## Техническая основа

- Обязательная зависимость: `SubworldLibrary` из Steam Workshop, без копирования его кода или бинарных файлов в репозиторий.
- Арена объявляется как `Subworld` фиксированного малого размера с генерацией пустой коробки, песчаного основания и точки появления.
- В одиночной игре используется документированный вызов `SubworldLibrary.Call("Enter", id)`. Multiplayer-переход будет реализован только после проверки актуального API библиотеки.
- Вход и выход сессии остаются серверно-авторитетными. Состояние боя передаётся между главным миром и subworld только через документированные `CopyWorldData`/`ReadCopiedWorldData` механизмы библиотеки.

## Сценарий

1. Игрок использует штатный Desert Medallion в пустыне основного мира.
2. Сервер проверяет отсутствие другой сессии и формирует список участников.
3. Участники переходят в `DesertScourgeArenaSubworld`. Основной мир не меняется.
4. Subworld генерирует арену и сервер subworld призывает Desert Scourge в её точке появления.
5. При смерти участника его `ModPlayer.OnRespawn` направляет его к точке возрождения арены, пока сессия активна.
6. После победы сервер фиксирует результат, возвращает участников в основной мир и очищает серверное состояние. Subworld является временным (`ShouldSave = false`).

## Calamity и риски

Desert Scourge в Calamity ожидает пустынный биом и использует глобальное состояние основного мира. Арена должна содержать достаточное число пустынных тайлов для `ZoneDesert`; до объявления совместимости обязателен прогон в одиночной игре. Multiplayer-прогон откладывается. Если босс не распознаёт биом, сценарий останавливается как несовместимый, а не подменяет Calamity AI.

## Не входит

- Сохранение/восстановление тайлов основного мира: после миграции оно не требуется и текущий `ArenaTileSnapshot` удаляется.
- Другие боссы, параллельные арены, multiplayer, dedicated-server гарантия и обработка аварийного падения процесса.
- Полная синхронизация всех модов, кроме подтверждаемого минимального случая Calamity + Subworld Library + Henrik's Boss Arenas.

## Подходы

1. **Subworld Library — выбранный.** Реально отдельная карта и встроенная модель subserver для multiplayer; цена — новая обязательная зависимость и обязательное игровое доказательство совместимости.
2. **Временная область основного мира — отклонён.** Не является «вне мира», остаётся видимой и уже продемонстрировал риск повреждения мира при неверном снимке.
3. **Отдельный `.wld` вручную — отклонён.** У tModLoader нет безопасного публичного API для такого переключения в активном сеансе.

## Проверки готовности

1. Сборка при установленной Subworld Library.
2. Одиночная игра: переход, призыв босса внутри арены, смерть игрока и возрождение на арене, победа и возврат.
3. После боя проверить основной мир: ни один его тайл не изменён.
