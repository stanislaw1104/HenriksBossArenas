# Дизайн: защита Desert Scourge arena

**Статус:** утверждён пользователем без дополнительного согласования.

## Цель

Не позволять изменять блоки арены и покидать её любым способом, включая blink и телепортации.

## Подходы

1. **Глобальные запреты изменений + ограничение позиции игрока — выбранный.** `GlobalTile`/`GlobalWall` отменяют добычу и взрывы только в активном Desert Scourge subworld. `ModPlayer` после обновления зажимает hitbox игрока между внутренними границами коробки и обнуляет скорость при выходе за них.
2. **Только неразрушаемые tile types — отклонён.** Не покрывает взрывы, модовые источники изменения мира и не предотвращает выход blink.
3. **Только стены коробки — отклонён.** Teleport может обойти коллизию или поместить игрока за пределами границы.

## Границы

- Защита работает только пока активен `DesertScourgeArenaSubworld`.
- Основной мир не изменяется.
- В singleplayer игрок не может ломать/взрывать тайлы и стены арены, а его hitbox остаётся внутри внутреннего прямоугольника коробки.
- Multiplayer/dedicated server остаются вне подтверждённой поддержки.
