# Разработка

## Сборка

Используется MSBuild-цель установленного tModLoader:

```powershell
dotnet msbuild HenriksBossArenas.csproj /p:TModLoaderInstallDir="C:\Program Files (x86)\Steam\steamapps\common\tModLoader"
```

`HenriksBossArenas.csproj` ориентирован на установленный tModLoader. При иной установке передавайте фактический путь через `TModLoaderInstallDir`; не фиксируйте личный путь в репозитории.

## Проверка перед коммитом

1. Выполнить сборку указанной командой.
2. Проверить `git status` и `git diff --check`.
3. Убедиться, что в изменениях отсутствуют токены, пользовательские конфигурации и сторонние бинарные файлы.
4. При наличии новых функций добавить и выполнить автоматические тесты до реализации кода.

## Границы текущего этапа

До отдельного разрешения не добавлять игровые механики, обработку призывов, телепортацию, порталы, генерацию арен или код синхронизации боёв.
