# Архитектура

## Текущий статус

Реализованы загрузочная точка, обнаружение NPC Calamity и отдельный временный subworld Desert Scourge на базе Subworld Library. Однопользовательский переход в карту вручную подтверждён. Отслеживание боя в subworld, возврат после победы, смерть/респавн и multiplayer пока не реализованы.

## Базовые ограничения будущей архитектуры

- Calamity Mod и Subworld Library — обязательные сильные зависимости.
- Состояние будущего боя должно управляться сервером и синхронизироваться с клиентами.
- Решение обязано поддерживать выделенный сервер и безопасно обрабатывать повторные события, подключения, отключения, смерть и возрождение игроков.
- Состояние боя после перехода должно быть перенесено на авторитетную серверную сессию subworld до реализации multiplayer.

## Текущее архитектурное решение

Площадка Desert Scourge генерируется как временный subworld размером 600×300. После штатного призыва в одиночной игре Subworld Library загружает эту карту, поэтому основной мир не изменяется.

Subworld-механика предоставляется внешней Subworld Library через внедрения и дополнительные subserver-процессы. Вход в subworld доказан одиночным игровым прогоном; сетевой протокол и dedicated server требуют отдельной проверки. Полный анализ: [ARCHITECTURE_RESEARCH.md](ARCHITECTURE_RESEARCH.md).
